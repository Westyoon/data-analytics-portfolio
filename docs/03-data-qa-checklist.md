# 데이터 QA 체크리스트

## 요구사항 정의

- [ ] 요청 목적과 최종 사용자를 확인했는가?
- [ ] 필요한 행 단위(grain)와 기준키를 정의했는가?
- [ ] 기간, 지역, 필터, 단위와 마감 시점을 확인했는가?
- [ ] `0`, `NULL`, 미수집, 미해당의 의미를 구분했는가?
- [ ] 개인정보·민감정보·외부 제공 제한을 확인했는가?

## 추출·전처리

- [ ] 원천과 추출 시각을 기록했는가?
- [ ] 중복키가 있는가? 있다면 허용되는 중복인가?
- [ ] JOIN 전후 행 수와 매칭률을 비교했는가?
- [ ] 문자열·날짜·코드·단위를 표준화했는가?
- [ ] 파생변수의 분모 0과 이상 범위를 처리했는가?

## 정확성·완전성

- [ ] 필수 컬럼 결측률을 확인했는가?
- [ ] 범주값이 허용 목록 안에 있는가?
- [ ] 수치 최소·최대·분위수가 현실적인가?
- [ ] 합계와 세부 그룹 합계가 일치하는가?
- [ ] 이전 배치 대비 행 수·핵심 지표 변화가 설명 가능한가?

## 모델 산출물

- [ ] 학습·검증 데이터의 기준 시점이 같은가?
- [ ] target leakage 또는 점수의 순환 정의가 없는가?
- [ ] 평가 모집단과 제외 조건이 문서화되었는가?
- [ ] baseline과 동일 metric으로 비교했는가?
- [ ] 잔차와 실패 사례를 확인했는가?
- [ ] 입력 데이터 변경 시 산출물을 함께 재생성했는가?

## 제공·인수인계

- [ ] 컬럼 정의와 단위를 함께 제공했는가?
- [ ] 필터 조건과 쿼리/스크립트 버전을 남겼는가?
- [ ] 품질 한계와 사용 금지 조건을 적었는가?
- [ ] 재실행 방법과 담당 후속조치를 정리했는가?
